# voxel_numba_kernels.py JIT-compiles the 5D A* / priority-A* / OR-reduce
# kernels that VoxelObstacleAStar invokes from arm_node_abs's
# plan_grasp_from_point and PlanToPose. Without numba, voxel_phase4_astar
# falls through to a stub that raises "numba A* priority kernel not
# available" on the first plan call. numba >=0.61 is the lowest line that
# accepts numpy 2.x; pip resolves llvmlite transitively.
numba>=0.61

# 缺失时自动回退为原始深度（仅打一条 warning）。原仓库 requirements 未
# 单独 pin scipy（通常由 torch/numba 传递装上），此处保持一致不强制。
